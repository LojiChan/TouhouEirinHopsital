【1. 这是个什么游戏？】
============================================================

《东方永琳诊所》是一款基于东方 Project 世界观的非官方二次创作文字医疗模拟游戏。
你将扮演八意永琳——永远亭的主治医师，在幻想乡接诊人类、妖怪、月人和妖精。
简单说，你负责诊断、处方和善后；幻想乡负责不断提出“这也算生物吗”的新问题。

这里有常规临床风格的病例，也有妖力干扰、魔法、超现实病理和违反常识的剧情。
在某些难度下，抽血可能抽出星星，听诊器可能传来八音盒，针头也可能对现实本身提出辞职。

游戏特色：
· 大量药物、治疗行动和医疗器械条目，可自由组合处方。
· 多个科室、难度和病例参数，从严谨模式到幻想乡物理学崩坏模式。
· 东方 Project 角色患者与随机生成的病情、主诉、病史和生命体征。
· LLM 参与病例叙述、治疗判定和剧情演出；本地 Ollama 与云端 API 均可选择。
· “月之头脑”辅助系统，可根据当前病例对药物、行动和器械进行分类。
· 游戏内包含存档、病例统计、资源浏览、背景故事、音乐盒和音量设置。
· 可选背景音乐和音效；相应依赖或资源不可用时，音频功能可能关闭。

LLM 生成结果具有随机性。同一病例、同一处方在不同模型或不同时间可能得到不同文本。
AI 不是裁判界的蓬莱药，偶尔会自相矛盾、格式错误或一本正经地胡说八道。
如果它把患者的脉搏写成“心情很好”，请相信仪器，不要给模型颁发行医执照。

【2. 快速开始】
============================================================

【系统需求】
· Windows。
· Python 3.10 或更高版本；建议从 python.org 安装并启用 PATH。
· Windows Python 安装需要带 Tkinter。
· requests：必需，用于 LLM API 和游戏中的网络请求。
· pygame：可选，用于音乐和音效。
· pypinyin：可选，用于中文排序等功能。
· Pillow：可选，用于显示图片资源。

【安装 Python 依赖——让永琳的电脑先活过来】

在项目目录打开终端，执行：

    python -m pip install requests pygame pypinyin pillow

其中 requests 是游戏网络请求所需依赖；pygame、pypinyin 和 Pillow 用于可选功能。
如果暂时不需要声音、拼音排序或图片显示，可以不安装相应可选依赖。
若某个可选依赖安装失败，可先移除该依赖再安装 requests；对应可选功能可能无法使用。
少了 pygame，音乐盒会保持沉默；少了 Pillow，图片可能缺席。它们不会因此向你寄投诉信。

【使用发布包——不需要把手术室整栋搬回家】

发布目录至少需要包含：
· TEHlauncher.bat
· TEHloader.py
· runner.tehrpa
· 游戏资源文件和资源文件夹

运行发布包不需要 TEHrunner.py，但仍需要 Python 环境。
双击 TEHlauncher.bat，按提示选择 LLM 模式。
也可以在项目目录执行：

    python TEHloader.py --load

runner.tehrpa 是自定义加密封包，不是 Python 脚本。不要执行 `python runner.tehrpa`。
那就像把病历袋塞进听诊器里要求它自己开药：工具没错，调用方式有点问题。

【本地 Ollama 准备——请先给模型准备一张椅子】

1. 安装并启动 Ollama。
2. 下载一个兼容模型，例如：

    ollama pull qwen2.5:7b

3. 确认 Ollama 服务正在运行，默认地址为 http://localhost:11434。
4. 启动游戏时选择本地 Ollama 模式。

实际可用模型与硬件要求取决于你选择的模型。大模型对内存和显存的需求可能很高。
如果电脑风扇突然开始模仿永远亭的直升机，不一定是妖怪，也可能只是模型太大。

【3. 核心玩法：如何不当一个庸医】
============================================================

【接诊流程——患者已经在候诊室了】

1. 在主菜单选择“新游戏”。
2. 阅读游戏内的免责与伦理提示；同意后继续，不同意则退出。
3. 选择科室、难度、幻想活性、突发状况、疾病罕见度、配合度和病程速度。
4. 阅读患者自述、主诉、病史、特殊检验数据和生命体征。
5. 在左侧资源列表选择药物、行动或器械，加入治疗槽。
6. 点击“发送处方”，等待 LLM 生成治疗结算。
7. 根据评分、病情变化和最新生命体征继续处理，或结束病例。

每次处方由你选择的项目组成。请仔细阅读病例和项目说明；治疗结果由游戏逻辑与 LLM 文本共同呈现。
游戏内的评分和医学内容仅用于娱乐，不具有现实医学意义。
如果结算结果不合常理，先别把责任推给实习生——本游戏没有实习生，只有你、永琳和一台很会续写的模型。

【主诉和配合度】

患者不一定愿意好好交代病情。配合度较低时，自述可能会隐瞒症状、装傻、反向挑衅，
或者声称自己觉得自己是一只蘑菇。

可以结合现有信息选择检查和治疗项目，但请记住：生成文本可能不完整或彼此矛盾。
在幻想乡，化验结果也不保证比患者本人更诚实。必要时多看一眼；仪器偶尔也会被妖力带偏。

【月之头脑——让一位月之头脑帮你看清药典，理论上】

在设置中开启后，游戏会请求 LLM 对可用项目进行分类，并在资源列表中显示辅助判断。
分类可能包括推荐、慎用、禁用或无关项。它是游戏内参考，不是现实药物安全系统。
模型可能漏项、误判或输出不完整；请勿把它用于现实医疗决策。
它是辅助按钮，不是能替你签字的第二位主治医师。

【4. 难度与模式：理智的边缘】
============================================================

【幻想活性】决定病例和治疗演出的现实程度。可用选项以当前版本界面为准。
它大致决定了现实法则今天是否值班，以及值班时有没有接电话。

· ……现实：尽量采用严谨临床风格，减少超自然现象。牛顿暂时可以回来上班。
· 极低 / 低：以现实病理为主，允许少量幻想干扰。
· 普通 / 高：妖力和异常生理现象逐渐增加。
· 极高：妖力显著干扰，常规检查和治疗可能出现离谱反馈。
· 完全的……梦境：现实法则主动离场，病例可以荒诞到难以用常识解释。请勿替它打卡。
· 随机：由游戏在可用范围内随机选择。

在高幻想活性下，可能出现“3号针管在静脉内玻璃状碎裂”之类的剧情。
这不是医学模拟器的科学突破，也不是给现实中的针管提出的新设计需求。

游戏另有 easy、normal、hard、lunatic、extra 等难度设置。不同版本的解锁和判定可能不同，
请以当前版本界面实际显示为准。若 Extra 已经开放，可能是版本设定，也可能是幻想乡忘记上锁。

【5. LLM 模式、网络连接与第三方服务——模型会说话，网络也会留下脚印】
============================================================

【云端 API】

选择云端模式时，游戏会把系统提示词和当前任务提示发送给配置的云端 LLM 服务，
用于生成病例、治疗结算、月之头脑分类和剧情文本。提示内容可能包含游戏角色资料、
虚构的年龄设定、病情、生命体征、治疗选择及部分历史记录。

项目当前配置的云端服务为 BigModel（请求模型为 GLM-4-Flash）。服务的可用性、价格、
额度、数据留存和处理方式由服务商决定，并可能随服务商政策变更。
请在使用前查看服务商最新的服务条款和隐私政策。请勿在游戏提示中输入真实病历、
真实姓名、联系方式、账号密码或其他敏感个人信息。

如果通过启动器输入自定义 API Key，该 Key 会用于对应的云端请求。
不要把 Key 发布到公开仓库、截图、日志或问题反馈中；若怀疑泄露，请立即在服务商处撤销或更换。
客户端程序无法可靠隐藏随客户端分发的凭据。

【本地 Ollama——把模型请到自家客厅】

选择本地模式时，LLM 请求默认发送至本机 Ollama（http://localhost:11434）。
如果你把 Ollama 配置到其他设备、代理或远程服务，这些中间服务也可能接触请求内容。

本地 LLM 模式不代表整个游戏完全离线。游戏其他功能仍可能访问下列网站。

【其他网络请求——“本地运行”不等于给网线放假】

· thwiki.cc：在部分病情生成流程中查询东方角色的公开资料摘要。
· pixiv.re：幕间剧情功能会尝试获取图片。
· BigModel：仅在云端 API 模式中作为 LLM 服务使用。
· localhost Ollama：仅在本地 LLM 模式中向本机模型服务发送请求。

访问外部网站时，对方可能接收到正常网络通信所需的信息，例如 IP 地址、请求时间和请求路径。
第三方网站的隐私政策、服务可用性和内容不受本项目控制。
断网时在线资料、图片或云端模型功能可能无法使用；本地模型也需要已在本机安装并启动。

【本地数据与日志】

游戏存档以 JSON 文件保存在项目目录下的 Saves 文件夹中，内容可能包括游戏设置、
患者进度、玩家选择、治疗结果和模型生成的文本。请自行管理存档，不要上传含个人信息的内容。

从当前项目代码中未发现专门的玩家账号系统或遥测/分析上传功能；但这不涵盖 Python、
Windows、网络服务商、LLM 服务或第三方网站自身可能进行的数据处理。
如果你运行的是经过修改的版本，请以实际代码和所连接的服务为准。

【7. 常见问题（Q&A）】
============================================================

Q：启动时提示找不到 runner.tehrpa？
A：确认 runner.tehrpa 与 TEHloader.py 位于同一目录，并从该目录启动。
它们需要并肩工作，不能一个在永远亭、一个在月都。

Q：能不能直接运行 runner.tehrpa？
A：不可以。它是自定义封包，不是 Python 源文件。请双击 TEHlauncher.bat，
或运行 `python TEHloader.py --load`。封包负责提供内容，加载器负责读它；
让封包自己启动，就像让处方单自己去药房排队。

Q：为什么启动时提示 Python、Tkinter 或 requests 不存在？
A：检查 Python 是否安装并加入 PATH；使用 `python -m pip install requests` 安装必需依赖。
Windows Python 安装还需要包含 Tcl/Tk（Tkinter）。没有 Tkinter，主界面就只能存在于永琳的想象里。

Q：Ollama 报错找不到模型？
A：先确认 Ollama 服务正在运行，再执行 `ollama pull qwen2.5:7b`，
或检查 information.tehp 中配置的模型名称和服务地址。模型没下载好时，它当然无法隔空读病历。

Q：云端 API 报错或额度不足怎么办？
A：确认网络可用、服务商接口和模型仍可用、API Key 有效且额度充足。
不要在公开 issue 或截图里粘贴 API Key。Key 不是患者腕带，不要挂在大厅公告栏上。

Q：本地模式为什么还会产生网络请求？
A：角色资料和幕间图片功能可能访问 thwiki.cc、pixiv.re。断网后这些功能可能失败，
但本地 Ollama 请求仍可在本机运行。网络请求清单请看上一节，别让“本地”二字替你拔掉网线。

Q：为什么没有音乐或心跳声？
A：检查是否安装 pygame，并确认 Music 和 SFX 目录中有可播放音频文件。
部分音频格式可能受系统编解码器影响；可尝试转换为 OGG 或 WAV。
如果还是安静，至少患者暂时没有被背景音乐吓到。

Q：游戏生成的医疗建议能照做吗？
A：绝对不可以。游戏内所有医疗内容仅用于虚构剧情和游戏性，不适用于现实医疗。

Q：为什么患者死了下一局又出现？
A：这很正常。永远亭的病历管理系统显然比现实世界的因果律更有弹性。
至于复诊挂号费，请询问永琳女士的财务部门（自己）——如果她愿意起床的话。

【8. 项目目录结构】
============================================================

TouhouEirinHospital/
├── TEHlauncher.bat       # Windows 启动器与模式选择（先选模型，再进诊室）
├── TEHloader.py          # SAKU 封包验证、解密并启动游戏
├── runner.tehrpa         # 加密后的主程序封包（不是可直接运行的脚本）
├── TEHpacker.py          # 开发者打包工具（源码更新后记得重新打包）
├── TEHrunner.py          # 主程序源码；发布运行时可以不附带
├── TEHaudio.py           # 音频模块（负责让诊室不那么安静）
├── information.tehp      # 游戏全局配置
├── CasePool.tehp         # 患者与病例池
├── sentences.tehp        # 游戏中的短句
├── MedicineGroups/       # 药物项目资源（请先看说明，再考虑堆进槽里）
├── ActionsGroups/        # 治疗行动项目资源
├── MechineGroups/        # 医疗器械项目资源（目录名按当前项目拼写）
├── MedGroups/            # 额外或用户自定义药物资源
├── Prompts/
│   └── teh_system.txt    # LLM 系统提示词
├── Music/                # 背景音乐
├── SFX/                  # 音效
└── Saves/                # 本地 JSON 存档

自定义或修改资源前建议先备份。资源格式错误可能导致项目缺失、列表不完整或读取失败。
开发者重新打包后，应使用 `python TEHloader.py --verify` 验证封包。
