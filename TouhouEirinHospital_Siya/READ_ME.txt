【1. 这是个什么游戏？】
============================================================

这是一款基于东方Project世界观的单机文字医疗模拟游戏。
你是八意永琳——永远亭唯一的主治医师。你要在这个充满了妖力干扰、反常识病理和一堆配合度极差的患者的地方，把各种人类、妖怪、月人、妖精从鬼门关（或者更糟糕的地方）拉回来。

游戏特色：
· 590 种药物 / 326 种行动 / 255 种器械（总有一款能毒死……不对，治好你的患者）。
· 28 个细分科目，从“全科”到“妖力科”。
· 85 位东方角色患者（从偷吃蘑菇的魔理沙，到装病的因幡帝）。
· LLM 驱动（本地 Ollama），AI 会亲自为你呈现极具戏剧性的病情恶化。
· “月之头脑”辅助系统（教你如何合法、合规、或者带点违法地使用猛药）。

【2. 快速开始】
============================================================

【系统需求】
· Python 3.10 或更高版本
· 必须安装 pygame（pip install pygame）—— 不然你什么都听不到，只能听到心电监护仪的脑补音。
· 最好装个 Ollama 跑个大模型（比如 qwen2.5:7b）。没有 AI，这游戏就成了纯粹的算命。

【安装步骤】
1. 装好 Python，打开终端。
2. 敲：pip install requests rich pygame pypinyin
3. 确保你的 Ollama 已经在后台悄悄运行（或者大声运行）。
4. 首次运行前，在项目目录执行 `python TEHpacker.py` 生成 `runner.tehrpa`。
5. 双击 TEHlauncher.bat 启动；也可以执行 `python TEHrunner.py --load`。

【3. 核心玩法：如何不当一个庸医】
============================================================

在左侧列表选药，在槽里堆叠，点击“发送处方”，让 LLM 判定你的生死。
每回合 3 次机会。3 回合后没把患者治好，或者治死了，那就是医疗事故。

【关于主诉和配合度】
别以为患者会乖乖交代病情。如果配合度低于“普通”，你看到的自述可能是“嘿嘿我不告诉你”或者“我觉得我是一只蘑菇”。
怎么办？
上“抽血化验”啊！
（然后你可能会看到抽出的不是血，而是发光的小星星，因为妖力干扰。）

【关于月之头脑】
在设置里开启后，你的药典列表会变成红绿灯。
深绿：完美对症，用吧。
浅绿：常规可用。
橙色：慎用。可能把人吃出幻觉，但能保命。
红色：禁用。除非你想看患者当场表演医学奇迹（物理）。
（注：月之头脑的判定有时候很死板。如果你坚持要在肝损伤的精神分裂症患者身上用冬眠灵，并且自己有把握控制剂量，那就用！医者，偶尔也需要一点疯狂。）

【4. 难度与模式：理智的边缘】
============================================================

游戏的【幻想活性】决定了这个世界到底有多疯。

· ……现实：非常严谨的临床模式。抽血化验都是正常的，你是个好医生。
· 极高：妖力显著干扰。
· 完全的……梦境：
  注意，这不是爱丽丝梦游仙境。
  这是“3号针管在静脉内玻璃状碎裂”的“噔噔咚”时刻。
  在这个模式下：
  - 你不仅物理法则失效，你连生物学都失效了。
  - 手臂静脉抽血会抽出逸散的脑脊液，听诊器里传来八音盒。
  - 你想用“威胁自由搏击”物理制服患者？她会百米冲刺跑路。

【关于 Extra 模式】
在打通 Hard 或 Lunatic 后解锁（不过可能你的版本是天生就有）。
在这个模式里，一切都有可能发生。
甚至……如果你运气不好（或者药给多了），处于安定（麻醉）状态的患者，可能会在某个判定中翻墙跑路。

【5. 常见问题（Q&A）】
============================================================

Q: 为什么我的背景音乐没有声音？
A: 第一步，检查是否安装了 pygame；第二步，检查你的 MP3 是否因为编码问题静音。如果不行，转成 OGG 格式，OGG 是亲爹。

Q: Ollama 报错找不到模型？
A: 因为你的 C 盘满了，而你把模型放到了 D 盘，却没有设置 OLLAMA_MODELS 环境变量。去系统设置里把变量加上，重启服务。

Q: 为什么我给了患者一管吗啡+芬太尼+氯胺酮，她不仅没死，还笑了？
A: 因为在“完全的……梦境”难度下，化学极乐是一种合法的治疗手段。只要生命体征没平，一切都好说。

Q: 我能给博丽灵梦开泻药吗？
A: 从医学角度不建议。从整活角度，我们非常鼓励。

Q: 为什么我治死的患者下一把又回来了？
A: 这很正常，很少有人解释为什么我们会疯狂的幻想。（你不会才知道永琳有蓬莱药和复活币吧？）
