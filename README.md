# TouhouEirinHopsital
# 东方永琳诊所 · Touhou Eirin Hospital

> **永远亭医疗模拟器：诊断、处方、检查，然后祈祷物理法则还管用。**

一款基于东方 Project 世界观的文字医疗模拟游戏。玩家扮演八意永琳，在永远亭接诊幻想乡的居民，通过问诊、检查、选择药物与治疗行动，处理从常见病到妖力失控的各种病例。

游戏使用 LLM 生成患者病情与治疗反馈，可选择本地 Ollama 或云端 API。病例、药物、行动、器械和提示词均由项目资源文件提供。

## 游戏内容

- 扮演八意永琳，在永远亭接诊东方 Project 角色。
- 使用病例、药物、行动和器械资源组合治疗方案。
- 由 LLM 生成患者主诉、病史、生命体征、治疗结算和剧情片段。
- 选择不同难度、幻想活性、突发状况、疾病罕见度、配合度和病程速度。
- 开启“月之头脑”辅助功能，获得药物、行动和器械的适用性分类。
- 保存与读取游戏进度，查看病例统计。
- 播放背景音乐和音效；缺少音频依赖时可关闭音频体验游戏。

游戏包含现实临床风格和高度幻想化的模式。幻想活性越高，病情和治疗结果越可能脱离现实逻辑。

## 运行环境

- **Windows**
- **Python 3.10 或更高版本**
- Windows Python 安装中需要包含 Tkinter。
- `requests`：必需，用于 LLM API 和游戏中的网络请求。
- `pygame`：可选，用于音乐和音效。
- `pypinyin`：可选，用于中文排序等功能。
- `Pillow`：可选，用于显示图片资源。

安装依赖：

```bash
python -m pip install requests pygame pypinyin pillow
```

如果只想体验游戏，可以不安装 `pygame`、`pypinyin` 或 `Pillow`；对应的音频、排序或图片功能可能不可用。

## 快速开始

### 使用发布包

发布目录至少需要包含：

- `TEHlauncher.bat`
- `TEHloader.py`
- `runner.tehrpa`
- 游戏资源文件和资源文件夹

发布包运行时**不需要** `TEHrunner.py`，但仍需要 Python 环境。双击 `TEHlauncher.bat`，按照提示选择 LLM 模式。

> `runner.tehrpa` 是加密数据包，不是 Python 脚本。不要使用 `python runner.tehrpa` 启动；应通过 `TEHloader.py` 加载，或使用启动器。

### 从源码打包

开发者需要保留 `TEHrunner.py`，并在项目目录中运行：

```bash
python TEHpacker.py
```

打包器会生成或更新 `runner.tehrpa`。之后可使用：

```bash
python TEHloader.py --verify
```

验证封包，或使用启动器运行游戏。

## LLM 模式与网络连接

启动器提供以下模式：

- **云端 API**：通过配置的云端模型生成内容。也可以输入自己的 API Key。
- **本地 Ollama**：向本机 Ollama 服务发送请求。默认配置使用 `http://localhost:11434` 和 `qwen2.5:7b`；请先安装并启动 Ollama，并准备相应模型。
- **自定义云端 API Key**：使用用户输入的 Key。请勿在公开仓库、截图或问题反馈中分享 API Key。

云端服务的可用性、计费、限额和数据处理方式由相应服务商决定。使用前请阅读服务商当时有效的服务条款和隐私政策。项目不保证内置云端配置一直可用，也不保证云端服务免费。

游戏还可能访问以下外部服务：

- BigModel 云端 API：用于云端 LLM 请求。
- 本地 Ollama 服务：仅在选择本地模式时用于 LLM 请求。
- `thwiki.cc`：部分幻想活性模式下查询角色资料。
- `pixiv.re`：请求幕间剧情所用的图片。

因此，选择本地 Ollama **不代表游戏完全离线**；上述资料和图片请求仍可能访问外部网站。若需要离线游玩，请断开网络，并接受相应在线功能不可用或降级。

## 游戏玩法

1. 在主菜单选择“新游戏”，阅读并确认游戏内的免责与伦理提示。
2. 选择科室、难度、幻想活性和其他病例参数。
3. 阅读患者自述、主诉、病史和生命体征。
4. 从药物、行动和器械列表中选择项目，组合治疗方案并提交给 LLM 判定。
5. 根据病例变化继续治疗，或查看结算并接诊下一位患者。

游戏中还提供存档、统计、音乐盒、资源预览和设置等功能。实际可用项目取决于当前版本附带的资源文件。

## 隐私说明

### 游戏本地保存的数据

游戏存档以 JSON 文件保存在项目目录的 `Saves` 文件夹中。存档可能包含游戏设置、患者病例进度、处方项目、治疗记录、统计信息和 LLM 生成的文本。请自行保管或删除存档；不要在公开问题、截图或仓库提交中附上含个人信息的存档。

根据当前项目代码，未见玩家账号注册或专门的遥测/分析上传功能。但这不涵盖 Python 运行环境、操作系统、网络服务商或第三方服务自身可能进行的数据处理。

### 发送给 LLM 的内容

当你使用 LLM 功能时，游戏会将系统提示词和当前任务提示发送给所选的模型服务。提示内容可能包含：

- 游戏内角色的姓名、种族、年龄设定、性格和病例资料；
- 症状、病史、生命体征、幻想活性及其他游戏设置；
- 玩家选择的药物、行动和器械；
- 当前病例的部分治疗历史；
- 月之头脑功能所需的药典、行动和器械资源文本。

云端模式会将这些提示发送到相应云端服务。服务商可能根据其条款处理请求数据、网络地址、请求时间和 API 使用信息。请勿输入真实姓名、联系方式、真实病历、账号密码、API Key 或其他敏感个人信息。

本地 Ollama 模式会将 LLM 提示发送到你配置的 Ollama 服务；默认地址为本机 `localhost`。如果你把 Ollama 配置到其他设备或代理，该设备或代理也可能看到请求内容。

### 其他网络请求

部分游戏流程会向 `thwiki.cc` 请求角色资料，并向 `pixiv.re` 请求图片。这些请求可能向相应网站暴露网络连接所需的信息，例如 IP 地址、请求时间和请求路径。其数据处理受各自政策约束。

本项目不控制第三方服务的可用性、保留期限或数据处理方式。隐私政策可能变更，请在使用前查看相关服务商的最新说明。

### API Key 安全

API Key 是敏感凭据。使用自定义 Key 时，请避免在共享设备上输入，并不要将包含 Key 的启动器输出、环境变量、代码或截图发布到 GitHub。客户端程序无法可靠隐藏随客户端分发的凭据；如果你维护自己的云端 Key，建议通过服务商控制台设置额度和权限，并在怀疑泄露时立即撤销或更换。

## 常见问题

**Q：启动时提示找不到 `runner.tehrpa`？**  
A：确认 `runner.tehrpa` 与 `TEHloader.py` 位于同一目录，并从该目录启动。

**Q：能否删除 `TEHrunner.py`？**  
A：发布运行时可以不附带它。开发和重新打包时需要保留源码以及 `TEHpacker.py`。

**Q：本地 Ollama 模式是否完全离线？**  
A：LLM 请求默认发送到本机 Ollama，但游戏中的角色资料和图片功能仍可能访问外部网站。

**Q：没有声音或图片怎么办？**  
A：确认安装了对应可选依赖，并检查 `Music/`、`SFX/` 文件夹及其资源是否存在。没有 `pygame` 时音频功能不可用；没有 `Pillow` 时图片可能无法显示。

**Q：游戏给出的医疗建议可以照做吗？**  
A：不可以。所有医疗内容均为虚构游戏文本，不适用于现实医疗。
